## My Learning
- **Terminal finally makes sense:** Commands like `pwd`, `ls -lah`, `cp`, `mv`, redirection (`>` vs `>>`), and pipes (`|`) went from confusing to second nature. I can navigate and manage files without touching Finder now.
- **The OS does way more than I thought:** Seeing 800+ processes running when I only had a couple of windows open was eye-opening. macOS is constantly juggling memory, permissions, and hardware access behind the scenes.
- **Numbers and text are all just bits:** Doing conversions by hand and then checking them in Python with `bin()`, `hex()`, and `ord()` made it real — everything from the letter "A" (65 in ASCII) to a webpage is stored as 0s and 1s.
